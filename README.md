# Personal Finance Expense & Budget Analysis Dashboard

## Project Overview
This project analyzes personal income and spending to show where money is going and how it compares to a budget. A transaction dataset was created in Microsoft Excel, with income and expenses calculated and summarized. The data was then cleaned and transformed with Power Query and visualized in Microsoft Power BI, using KPI cards and interactive visuals for expense analysis.

## Tools Used

| Tool | Purpose |
|------|---------|
| Microsoft Excel | Create the transaction dataset, calculate income and expenses, and prepare summaries |
| Microsoft Power BI | Build interactive dashboard visuals, KPI cards, and expense analysis |
| Power Query (within Power BI) | Clean and transform data, if required |
